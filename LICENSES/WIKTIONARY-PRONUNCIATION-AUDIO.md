# Wiktionary / Wikimedia Commons Pronunciation Audio

The word-to-recording association comes from the English Wiktionary pronunciation
section. The audio recordings are separate works; the Wiktionary text license is
not used as evidence for an audio license. Each accepted file below was checked
against the saved Commons `videoinfo` response referenced by `metadataSha256` in
`src/pronunciation-audio/data/pronunciation-audio.json` and in the change's
`evidence/coverage.json` report.

No recording is modified by this project. The MP3 candidates are Wikimedia's
official transcodes of the same recording, not separately guessed URLs.
